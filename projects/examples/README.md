# Project Planning Examples

These are real project artifact examples from Blue Builder workstreams.
Use them as references for quality and structure when writing your own `PRD.md`, `SPEC.md`, and `TASKS.md`.

## Included examples

- `rapidintel/` — architecture-heavy Cloudflare product planning
  - Strong PRD persona framing + signal-quality guardrails
  - Deep SPEC covering D1/DO/Queues/Workflows patterns
  - TASKS with acceptance criteria, required tests, verification plans, and evidence

- `smb-scheduler-blue/` — launch readiness and production hardening
  - PRD aligned to customer-readiness outcomes
  - SPEC with validated blockers and workstream decomposition
  - TASKS with explicit test evidence and go-live gate tracking

## Notes

- Examples are snapshots and may include project-specific IDs/paths.
- Treat these as reference artifacts, not drop-in templates.
- Use `projects/_templates/` for clean starter files.
